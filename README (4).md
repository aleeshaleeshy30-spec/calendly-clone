# Calendly Clone

A modern, responsive scheduling platform clone built as part of CWI TASK : 40.

## ✨ Features

- Clean, professional landing page
- Interactive calendar with date selection
- Multiple available time slots
- Booking confirmation flow
- User Dashboard (Upcoming + Past meetings)
- Fully responsive design
- Smooth UI interactions

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Font Awesome
